# 2000s likeness review — batch 01

Reviewed September 26, 2026. At the user's request, moved to the 2000s after
2010s batch 01. Selected 35 players by career value among unresolved Madden 27
faces without an individually recorded tone, using entry years 2000–2009.
The remaining 2020s and 2010s queues are preserved.

## Findings and scope

Seven generic palette corrections: Julius Peppers 7→6, Kevin Williams 7→6,
Steve Smith Sr. 3→5, DeMarcus Ware 7→6, Lance Briggs 7→6, Matt Forte 7→5,
and Derrick Johnson (Texas) 7→6. The other 28 choices were retained and recorded.

No new usable Madden 27 head matches were established. Catalog checks covered
exact names, normalized suffixes and asset-name variants. The following players
have preset-only catalog entries, which remain excluded under the existing
policy: Julius Peppers, Eli Manning, Brian Urlacher, Terrell Suggs, Kevin Williams, Steve Smith Sr., Haloti Ngata, Steve Hutchinson, Marshal Yanda, Vince Wilfork, Eric Weddle, Anquan Boldin, Joe Staley, Josh Sitton, Derrick Johnson. A portrait or preset directory is not evidence of a
renderable head. All 35 remain generic in Madden 27; existing Madden 26 face
resolution and game-specific portrait selection are preserved.

Derrick Johnson's correction uses `derrick|johnson|2005|texas`, because the
pool also includes the Washington cornerback drafted in 2005. Alex Smith's
existing Utah-specific entry is preserved; he was excluded from this new batch.
Matt Light remains queued because this pass lacked a named local portrait for
him. Neither a missing photo nor a same-name entry is treated as a completed review.

## Validation and remaining work

`Likeness2000s.test.ts` checks all 35 recorded choices, preset exclusion,
parsed Madden 26/27 exports, Madden 27 roster additions, manual generic-face
precedence and college-qualified namesake separation. The initial tests failed
on unrecorded curation and incorrect exported tones; the additional namesake
test caught an unqualified Derrick Johnson key before it was narrowed to Texas.
All five targeted tests pass. The full server suite passed 384/384 with no
skips, and server TypeScript checking passed on September 26, 2026.

The overview now counts college-qualified curation, matching DraftEnrichment.
Before this batch, 3,209 players needed tone review, rather than the previously
reported 3,210 (Alex Smith was omitted from that tally). After recording these
35 players, the 2000s has 73 resolved faces, 36 generic players with recorded
tones (35 new plus Alex Smith), and 3,174 without recorded tones, out of 3,283.

These changes apply to newly generated draft classes and roster additions.
Existing exports and stored appearance snapshots are not rewritten. Exact
generic head shape, hair and in-game appearance remain pending. This batch
does not complete the decade or the automatic likeness-generator feature.
The user moved to the 1990s after this batch; the remaining 2000s queue is preserved.
