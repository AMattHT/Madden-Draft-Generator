# 1970s likeness review — batch 01

Reviewed September 26, 2026 against the linked, identified player photographs.
Scope: the 35 Hall of Famers entering the NFL in 1970–1979 who had no recorded
tone in the shipped overlay and no verified Madden 27 scan in the current catalog.
Draft/entry year, rather than the decade a player was most famous, determines the batch.

## Result

Eight clear mismatches corrected; 27 existing coarse palette choices retained
and recorded. All 35 now have a curated tone. The numbers are Madden's palette
indices, **not race labels or precise complexion measurements**. Photos have
different lighting, age and color balance; this pass checks broad consistency.
Close shade comparisons remain open, particularly Franco Harris, Mike Haynes
and Kellen Winslow. Their existing choices were retained rather than guessed anew.

No individual generic head, hairstyle or facial geometry is certified by this
pass. Those remain pending for all 35. The current matcher chooses from the
reviewed tone pool and can choose a different head at another board position.
Verified game scans and manual user edits retain their existing precedence.

## Why the existing inference missed them

Tony Dorsett's cached wiki estimate was 4, but the combined evidence/prior
produced tone 2. John Stallworth similarly produced 2. Joe Klecko's cached wiki
estimate produced 7. Five other corrections had cached portraits/headshots,
so a review queue that skips everyone with a photo would never catch them.
Curated choices already take precedence over these estimates in DraftEnrichment;
no demographic prior or global image-classification threshold was changed.

## Verification and application

`Likeness1970s.test.ts` checks all 35 recorded values, regeneration through Tony
Dorsett's draft class, Dallas team class and custom board, parsed Madden 26 and
27 exports for the whole batch, Madden 27 roster-add generation, and user override
precedence. Run from `server`:

```powershell
node --import tsx --test src/services/__tests__/Likeness1970s.test.ts
```

Validation on September 26, 2026: all four batch tests passed, the complete
server suite passed 370/370 with no skips, and server TypeScript checking passed.
The batch tests reproduced the Dorsett and Cliff Harris failures before the
curated-data change.

The change applies when generating a class or adding players to a roster. It does
not rewrite already-exported files or replace the appearance snapshot of a player
already added to a saved roster project. Existing manual appearance edits win.
Actual in-game rendering still needs a visual check after export.
