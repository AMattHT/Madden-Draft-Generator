# Likeness review work order

User-directed order, September 26, 2026: **2020s → 2010s → 2000s → 1990s →
1980s → 1970s → 1960s → 1950s → 1940s → 1930s**. Use draft/entry year, not
the decade of a player's peak career. Work in batches of 25–50 within each decade.
The 2020s currently means 2020–2026 in this database.

Preserve completed reviews. Start with reported problems, then prominent players
and early picks without resolved game faces. Do not skip a player simply because
a photo measurement or URL exists. Check for catalog name variants before
assigning a generic replacement. Compare visible appearance to the game's
palette; do not assign demographic labels or derive likeness from names.
