# 1930s likeness review — batch 01

Reviewed September 26, 2026. Scope: 25 players with database entry years in
1936–1939, without existing curated tones or resolved Madden 27 faces.
Entry year determines the batch, not peak career or Hall of Fame induction year.
The 520 earlier curated keys, including seven existing 1930s choices, are preserved.

## Result

Recorded 25 retained generic-tone choices. No supported tone correction or
additional usable Madden 27 scan mapping was established in this batch.
The existing era fallback happened to agree with each broad palette choice;
these players now have individual curated records with named photo references.

This completes the first batch pass through the requested decade order,
2020s down to 1930s. It does not complete any decade's outstanding queue or
the entire likeness generator. Exact generic head shape, hair and in-game
appearance remain pending for every player in this batch.

## Identity and scan safeguards

The source profiles use William Shakespeare, Bob Hamilton, John Pingel and
Byron White. Their schools and playing dates match the database entries Bill
Shakespeare, Bob (Bones) Hamilton, Johnny Pingel and Whizzer White respectively.
The curated keys use the database spellings; no broad alias is introduced.
Davey O'Brien's apostrophe is normalized by the existing service. No selected
player needed a college-qualified key for a same-year namesake.

Sammy Baugh's raw catalog entry, baughSammy, is marked preset+lookup in both
games. It lacks a usable head bundle under the normal resolver settings and
remains generic. Preset-head opt-in was not enabled. Catalog checks included
the source-profile name variants as well as the database names.

The local plpo_WilsonGeorge.jpg shows a modern player and was excluded as a
reference for the 1937 Northwestern George Wilson. That historical entry
remains unreviewed, with tests guarding against accidental curation or a
resolved modern face. The seven earlier 1930s choices remain unchanged, as
do the prior decade corrections including Joe Perry and Tony Dorsett.

## Application and validation

Newly generated draft classes and roster additions use these records.
Verified game faces and manual edits retain their existing priority. Existing
exports and saved roster appearance snapshots are not rewritten.

Likeness1930s.test.ts checks all 25 curated records, actual enrichment source,
unresolved Madden 27 faces, parsed Madden 26/27 exports, Madden 27 roster
additions, manual-face priority, nickname keys and unreviewed-player isolation.
Before the data change, the tests reproduced missing curated records and
enrichment reporting era rather than curated evidence. No exported tone
mismatch was claimed for this retained-choice batch.

Validation: all five targeted checks passed; the full server suite passed
419/419 tests with no skips; server TypeScript checking passed. The data audit
confirmed exactly 25 added keys and all 520 earlier values unchanged.

Live lookup coverage after this batch: 508 players, zero resolved Madden 27
faces, 32 recorded generic tones and 476 generic tones still unreviewed.
