# 2010s likeness review — batch 01

Reviewed September 26, 2026. At the user's request, moved to the 2010s after
2020s batch 01; the remaining 2020s queue is preserved. Selected 35 players from
2010–2019 by career value among players without a resolved Madden 27 face or
recorded tone. All 35 had usable named portrait references. Before this pass,
2,378 players in this decade needed this review; 2,343 remain.

Slay, Tate and Gurley have actual head bundles in both game catalogs under
suffixed names, but their entries lacked owner-name and portrait metadata.
Judon's Matthew-named roster head appears only in the Madden 26 catalog.
The reviewed aliases are scoped to each player's exact entry year and still
require the asset in the target game. No global nickname or suffix guessing was added.

Evidence: `server/data/lookups/face-assets-by-game.json` supplies per-game
head availability and portrait inventories. `PID_Portrait_Mapping.csv`
supplies the named portrait/PID pairs. PIDs are used only when the target game
ships that portrait. The asset-based portrait correction also applies when a
user manually selects one of these three scans. Madden 27 exports keep their
existing tone-matched generic portrait fallback for Tate and Gurley; restoring
a 3D head does not restore absent menu artwork.

## Validation and remaining work

`Likeness2010s.test.ts` checks all recorded tones, both games' scan and portrait
mappings, exact-year guards, parsed Madden 26/27 draft exports, Madden 27
roster-add generation, manual generic-face precedence and Judon's per-game
availability. Tests also check that absent Madden 27 menu artwork falls back
to a portrait in the recorded tone group. Existing Madden 26 custom portrait
slots retain priority during draft export.

The new tests initially reproduced missing scan matches and incorrect exported
tones. All five targeted tests pass. The full server suite passed 379/379
with no skips, and server TypeScript checking passed on September 26, 2026.

These changes affect newly generated classes and roster additions. Existing
exports and saved roster appearance snapshots are not rewritten. Exact generic
head shape, hair and in-game rendering still need review. Preset-only entries
(e.g. Andrew Luck and Antonio Brown) remain excluded under the existing policy;
a portrait or preset directory alone does not establish a renderable head.

The user moved to the 2000s after this batch; keep the unreviewed 2010s queue
for later bounded batches. Earlier decades and the unfinished 2020s queue remain
tracked in the work-order overview. This is a first batch, not a completed decade
or completed automatic likeness generator.
