# 1970s likeness review — batch 02

Reviewed September 26, 2026. This pass covers 25 additional players entering the
NFL in 1970–1979, including undrafted players, beyond the 35 players in
[batch 01](1970s-batch-01.md). All previously recorded tones are preserved.

## Result and scope

Eleven mismatches corrected; 14 existing coarse palette choices retained and
recorded. No new Madden 27 scan mapping was established. The indices below are
game palette choices, not demographic labels or precise complexion measurements.
The batch prioritizes prominent players and clear errors with usable named
references. It does not finish the decade.

Ahmad Rashad's monochrome local portrait was supplemented with the Vikings'
[named playing-era photo](https://www.vikings.com/team/front-office-roster/ahmad-rashad).
Reggie McKenzie's identity/era was also checked against
[Michigan's profile](https://mgoblue.com/news/2017/2/16/football-reggie-mckenzie-from-lead-blocker-to-civic-leader).
The Broncos' individual Tom Jackson URL currently returns a missing page; the
linked Ring of Fame index supplies his named photograph instead.

Monochrome references include Ottis Anderson, Wes Chandler, Archie Manning,
Dwight Clark, Charle Young, Matt Blair, Reggie McKenzie and John Dutton.
These support broad consistency checks only. Fine shade review remains open,
especially for Blair and McKenzie, whose correction replaces the clearly light
default but does not certify a precise shade. Jim Plunkett, Rod Martin, Jack
Tatum and Drew Pearson retain their prior choices; lighting and small historical
images do not justify a confident adjacent-shade change. Nat Moore's reference
is a later-life official headshot. Exact generic head shape, hair, and in-game
appearance remain pending for all 25.

## Identity safeguards and remaining queue

Portrait filenames are not enough to establish identity. The local Mike Reid
image depicts a modern Panthers player and was rejected for the 1970 entrant.
Likewise, do not use newer Clay Matthews, Stanley Morgan, Gary Johnson, Charlie
Johnson, William Gay, Mike Thomas, Mike Bell or Mickey Shuler portraits for
their older namesakes. Ted Washington's legend reference belongs to the 1991
entrant, not 1972. Substring matches such as Dan Alexander/Danario Alexander and
Steve Nelson/Steven Nelson were rejected. These candidates remain pending.
Chuck Foreman's historical portrait uses the existing filename spelling
`plpo_legends_FormanChuck.jpg`; this is artwork, not evidence of a usable scan.

## Application and validation

The 25 additions use normalized name plus entry-year keys. Verified scans and
manual edits keep their existing priority. Newly generated classes and roster
additions use these choices; existing exports and saved appearance snapshots
are not rewritten.

`Likeness1970sBatch02.test.ts` checks all 25 choices, unresolved M27 heads,
parsed Madden 26/27 draft exports, Madden 27 roster additions, manual-face
precedence, older corrections and unrelated namesakes. Before the data update,
the tests reproduced missing curation and an exported tone mismatch.

Validation on September 26, 2026: all five batch tests passed, the full server
suite passed 399/399 with no skips, and server TypeScript checking passed.
The data audit confirmed all 410 previously recorded entries were unchanged
and exactly 25 entries were added. Git whitespace checking passed.

Coverage after this batch: 4,434 pool players, three resolved Madden 27 faces,
104 generic players with recorded tones, and 4,327 without recorded tones.
The two documented 1970s batches review 60 players; the coverage total also
includes earlier curation. Actual in-game rendering still needs verification.
Next in the requested newest-to-oldest order: the 1960s, preserving the remaining
queues for every decade. See [work order](README.md).
