# 2020s likeness review — batch 01

Reviewed September 26, 2026. First modern batch: 25 players from the 2020–2026
pool, prioritized by career value among unresolved Madden 27 faces, then limited
to named portrait references that could be reviewed this pass. The database had
484 unresolved/unrecorded players in this decade before the pass; 459 remain.

## Findings

Three players already had catalog faces under alternate first names. Restored
those exact assets for the reviewed entry year only, and only when present in
the target game's catalog:

The local game catalog provides the asset and PID pairing. These are explicit

Among the 22 players still using generics, nine palette choices changed and 13
were retained. All 25 received recorded palette choices, including fallback
tones for the three restored catalog faces. These are visible-appearance choices
within Madden's palette, not racial labels or precise color measurements.

## Validation and remaining work

`Likeness2020s.test.ts` covers the recorded tones, restored assets and portraits,
rejection of historical namesakes, parsed Madden 26 and 27 draft exports,
Madden 27 roster-add generation and manual face-override precedence. Madden 26
keeps its existing custom-portrait-slot behavior when a slot is assigned.

Validation on September 26, 2026: four batch tests passed; the full server suite
passed 374/374 with no skips; server TypeScript checking passed. Before the
changes, the tests reproduced the missed Rousseau face and wrong tone in export.

The corrections apply to newly generated classes and roster additions. Existing
export files and stored roster-player appearance snapshots are not rewritten.
Exact generic head shape, hair and in-game rendering still need review; this pass
does not claim the automatic likeness-generator feature is complete.

For the next batch, investigate Rodney Thomas II, Daniel Thomas, Eric Johnson
and Anthony Johnson with careful same-name/source checks. These remain queued; the user requested moving to the 2010s after this batch. Tedarrell Slaton's M26
catalog uses T.J. Slaton, but his M27 asset availability was not established in
this pass; do not treat an M26 match alone as a verified M27 head.
