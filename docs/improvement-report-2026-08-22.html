The short version

The engine is in good shape: both .mdc layouts round-trip against real game files, generation is deterministic, and the class shape (mean 66, max 84, dev-trait rates) reproduces Madden's own. The problems are in what gets written into the file, not the file format.

Three things stand out. First, who is good: the 2025 class ranks a long snapper and two kickers as its top X-Factors while Cam Ward and Travis Hunter sit at 67 Normal; combine numbers are mapped without regard to position (a 41-speed left tackle); injury and toughness rise with overall. Second, Madden 27 correctness: the writer never updates the header's prospect count (the game's own classes say 389; the tool writes 402 under that header), and the portrait-PID and commentary-ID offsets are swapped — which is why generic M27 rookies have no portrait. Third, nothing protects the work: six weeks including the entire M27 port are uncommitted, there were no tests until today, and one async route exception can take the API down.

1 · Rating realism — who is good, how good, and why

This decides whether a historical class is fun to draft. The class shape is right; the ordering and the attribute profiles inside it are not.

2025 class is mis-ranked: LS/K/P are the top X-Factors

CriticalSmall

Reproduced: Julian Ashby (LS, pick 251) 84 OVR X-Factor, two kickers 81/79, four undrafted K/P at 78 Superstar; Cam Ward / Travis Hunter / Abdul Carter / Mason Graham 67 OVR Normal. Cause: careerTo backfill at DraftEnrichment.ts:85 makes one-season rookies look like completed careers, then careerWavEstimate plus the K/P/LS anchor floors (RatingService.ts:26-28, which start at 60) push specialists above everyone.

Fix Use careerWavEstimate only when seasons ≥ 3 or Pro Bowls/All-Pros > 0, else the draft-slot prior; blend short careers with the slot prior (w = seasons/(seasons+3)) instead of the hard 1.5× boost; normalise K/P/LS floors to 55; stop stamping current-year rookies' nflverse wAV as "actual".

Combine numbers map without regard to position

HighMedium

One 40/bench/vert/cone table (DraftClassBuilder.ts:102-134) is applied to every position: a 5.2-second left tackle gets 41 speed where Madden's floor for LT is ~56; speed/strength/agility are FIXED_ATTRS, so the reconciler then inflates skill attributes to hit the target overall.

Fix Score each drill as a percentile within the position (nflverse combine.csv) and place it on that position's Madden attribute distribution; emit per-position min/max from the calibration build.

Injury, toughness and stamina rise with overall

HighSmall

DraftClassBuilder.ts:262-269 adds the OVR delta to every non-fixed attribute; reconcileToTarget only touches weighted attributes, so off-position ones keep the full shift. Regenerated 2000 class: corr(OVR, injury) = 0.89. In Madden's own classes it is ≈ 0.

Fix Three attribute classes: fixed physicals; OVR-driven = only attributes with non-zero weight in the prospect's ovrweights entry; everything else sampled around the position mean.

Almost no RT/RG, and pre-2001 almost no safeties

HighMedium

Lookup counts: LT 3,139 vs RT 79; LG 2,468 vs RG 88; SS+FS+S 504 vs CB 3,865. PositionMapper maps OT/T → LT and G/OG → LG and only edges and LBs are balanced (the LB half was fixed today).

Fix Add balanceCohort([LT,RT]) and ([LG,RG]) (side is cosmetic, same rating group); read depth_position from the depth charts for 2001+ DBs; split pre-2001 "CB" rows CB vs S by build. Also: DT is under-represented (18–34 per class vs Madden's 42).

Undrafted and supplemental stars rate at the floor

HighMedium

4,201 "UD" rows; 2 have wAV. Kurt Warner, Warren Moon, John Randle, Romo, Gates, Welker, Priest Holmes, Vinatieri, Bosworth — all rated as scrubs.

Fix One-time backfill: join UD rows to nflverse players.csv for the PFR id, fetch career AV/PB/AP/seasons into udfa_careers.json; minimum viable: grow the MANUAL map with ~40 famous UDFAs.

The 1960 AFL draft parses as entirely undrafted

HighSmall

230 rows have Round "AFL 1" / Pick "ALF 1" (sic); toInt returns null, so 1960 AFL has 0 rounds and Bob Talamini (wAV 62) sits at index 428. 1967–69 are mislabeled "AFL" after the common draft began.

Fix Accept "AFL n" in the loader, fix the "ALF" typo, relabel 1967–69 as common draft.

Realistic mode is pure hindsight with a fixed class shape

MediumMediumYour call

DraftClassBuilder.ts:559-583 ranks by career outcome and maps rank to one curve: Tom Brady (pick 199) is the top QB of 2000 at 83 X-Factor; 1983 = 2000 = 2013 in strength. CPU teams draft by how careers turned out.

Option A "hindsight" slider blending slot-expected wAV with actual wAV for the OVR rank (dev trait keeps carrying the true outcome), plus auto-scaled class strength from the class's top-32 summed wAV. Some users want the known-outcome board; make it a choice.

Smaller rating items

Medium

QB archetype raw career rush totals tag Brady/Roethlisberger/Matt Ryan as Scramblers (ArchetypeService.ts:189) — normalise per game. Variance flat ±3 on every attribute; calibration stores means only — emit per-position std/min/max. OVR recompute disagrees with Madden for OT Power/Agile, C, LS, CB Slot (264 mismatches over 2,010 real prospects) — regress true DesiredLow/High and add an integer pass. Era-blind bio 1950 LT = 78 in / 318 lb from M26 norms; hometown state defaults to Alabama (id 0) for ~66% of players.

2 · Madden 27 correctness

The app defaults to M27, but the M27 path drops prospects, writes two ids to each other's offsets, zeroes fields the game reads, and the franchise tools are M26-only.

Header prospect count at 0x42 is never written

CriticalTinyVerified

Checked directly: u16@0x42 = 389 in the M27 template, all four game-generated TEST classes and the tool's own 2003/1987 exports; = 402 in every M26 file. The game's own M27 classes fill exactly 389 of 455 blocks (224 drafted + 165 UDFA). The tool writes 402 prospects under a header that says 389, so picks 390–402 are most likely ignored on import.

Fix buf.writeUInt16LE(prospectCount, 0x42) in M27Writer.writeM27DraftClass (assert it in the M26 writer too), then decide the M27 class size deliberately and confirm with one in-game import. Also: the "455-slot URFA pool" in M27-PORT.md is wrong — the game uses 389.

Portrait PID and commentary ID are swapped (0x94 / 0x9e)

CriticalTinyVerified

In the game's TEST1 class every generic head maps to exactly one value at 0x94 (196/196 — gen_2_H_GM_004 → 4196 = plpo_generic_2_H_GM_004) and every surname to exactly one value at 0x9e (338/338). M27Parser.js:37-38 has them the other way round (commentary at 0x94 "tentative", PID at 0x9e). This is why generic M27 rookies import with no portrait and why the PID=0 workaround exists.

Fix Swap the two entries in M27_FIELDS and M27Writer.js:67-68; delete the PID=0 workaround at DraftClassBuilder.ts:309-315; build a head → PID table from the game classes; build surname-commentary.json from the career save so announcers call names in both games.

Fields the game reads verbatim are written as zero

HighMedium

Cross-referencing TEST3 rookies with their Player rows: 0x48 = birthdate (390/390; encoding (day<<11)|((month-1)<<7)|(year-1940)), 0x70 = PersonalityRating (never 0 in game classes), 0x96 = QB style, 0xf2 = Focus, 0x6b = 127 constant, 0x7d = 1. M27-PORT.md calls Focus "game-derived"; it is copied from the file.

Fix Add these to the field map: birthdate from nflverse (clamp pre-1940), PersonalityRating sampled from the game distribution, Focus by archetype with the observed 55/8/8/29 mix, QB style by archetype, the two constants.

Persona DNA is calibrated on veterans, not rookies

HighMedium

Over 1,556 game-generated rookies: slot count is 5 in 1,555 of them, WinAtAllCosts appears on 24 (so the "filtered out" note is wrong), ten traits never occur for rookies. The tool writes 3–5 slots from veteran frequencies.

Fix scripts/build-m27-rookie-persona.js deriving per-position-group and per-dev-tier frequencies from the TEST files; fill 5 slots.

M27 gear and faces drift

HighMedium

EraGearService.ts:448 calls helmetPool() and never reads era.helmet, so the M27 helmet pools are dead and 1980–2007 classes write GearHelmet_Standard/Schutt, which M27 doesn't have. The M27 allowlist path (GearOptionsService.ts:236) never loads. m27-face-assets.json contains 7 entries written by the tool's own earlier import (Witten, Gates, Polamalu, Romo, Suggs…), and the year guard takes the first same-name row.

Fix Move m27-game-gear-assets.json under data/lookups and generate the M27 pools from it; map vintage shells to the oldest surviving M27 asset; rebuild the face map from a clean save keyed by name + draft year; run the 5-player test that settles whether M26 legend face ids render in M27.

Franchise tab is M26-only while the app defaults to M27

HighLarge

FranchiseService.savesDir() hard-codes Madden NFL 26/Saves; no route accepts a game version; cap scaling is a silent no-op on M27's new contract model (guarantees, void years).

Fix Thread gameVersion through FranchiseView → api → routes → service; refuse a save whose gameYear doesn't match; add an M27 cap branch via the Contract ref. Also: madden-franchise's record proxy accepts unknown field names silently, so tool "counts" are attempts, not verified writes — validate against the table schema and count via field.isChanged.

3 · Likeness and presentation

What you see on the board and in cutscenes.

Greyscale legend portraits classify as dark skin

HighMedium

pid_skintone.json: Unitas → 7, Bart Starr → 7, Otto Graham → 7, Sammy Baugh → 7 (all Race = 1 in both CSVs). Near-neutral RGB makes the ITA angle meaningless. Separately, the position prior discards real photo evidence for white skill players (Csonka, Largent), and the prior itself is modern demographics applied to 1936–1945 classes.

Fix Detect low-chroma face boxes and mark them "greyscale" so the waterfall falls through to the CSV race or a colour photo; make the prior a per-decade curve; trust a derived tone when the skin-pixel pass had enough pixels.

Wikipedia photo URLs are name-only matched

HighMedium

453 of 5,861 URLs are SVG icons; 271 URLs are shared across draft years covering 1,126 rows (1942's Bruce Smith gets the Virginia Tech DE's photo). These feed portraits, skin tone and gear observation.

Fix Drop SVG/icon URLs and cross-year-shared URLs at load; validate hits against draft year/position from the infobox.

Vintage M26 classes inherit 2026 accessories

HighMedium

EraGearService.loadoutElements writes helmet, facemask, shoes, gloves, visor and the era extras only; arm sleeves, spats, mouthpiece, shoulder-pad size and knee/thigh pads come from the 2026 donor.

Fix Extend the era extras with pads (large pre-2000), no sleeves before ~2000, no spats before ~2010, no mouthpiece before ~1995, and emit explicit None assets for M26 so donor slots are overwritten.

Smaller presentation items

Medium

Generic heads light tones collapse to 4 faces (tone 2 has 36 heads but the "true generic" filter keeps 4) — raise the threshold. Announcers PLYR_COMMENT is a surname-keyed id; exports leave it 0 for most players and the CSV CommID is in a different id space.

4 · Reliability and verification

Six weeks of work, including the entire M27 port, is uncommitted

CriticalSmall

HEAD is 2026-07-09; 96 dirty files (49 modified, 47 untracked) including the root package.json that npm run dev needs, the M27 template, M27 parser/writer, persona/archetype services. A fresh clone cannot run.

Fix Commit now in logical chunks; decide LFS vs a download step for the 2.7 MB template and 2.9 MB gear JSON. Today's classifier work adds to the pile.

One export-side exception kills the API

HighSmall

Express 4 + Node 24: an async handler throw exits the process despite the error middleware (reproduced). routes/draft.ts and routes/export.ts have async handlers with no try/catch; no unhandledRejection hook.

Fix An asyncHandler wrapper, process-level rejection loggers, server.on('error') with an EADDRINUSE message, bind to 127.0.0.1 and restrict CORS to the Vite origin (the franchise routes write into your Saves folder).

No tests, CI or linter (until today)

HighMedium

Today added node --test via tsx with 36 tests for the classifier, scheme lookup, career loader and LB balancer. Nothing yet covers the export pipeline; verify-export.js builds from the raw lookup, not enrichedClass(), so it doesn't exercise what the UI exports.

Fix Golden-file tests building 2003/1965/2025 through enrichedClass + buildMdc/buildMdc27 asserting round-trip, header count, computeOverall === overall, top-5 picks in the top 40, no K/P/LS in the top 50; a GitHub Actions typecheck + test job.

HighMedium
